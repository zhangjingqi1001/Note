# 一、const

之前声明变量有三个，var、let、const

* var是我们不用考虑的，因为他马上就要被淘汰了

* 剩下let、const，我们建议const优先，尽量使用const

> const声明常量
>
> 如果有一个变量里面存的值不做改变，我们就是用const
>
> 有了变量先给const，如果发现需要修改，则再改为let



向下面这种事不可以将let变量改为const变量的

![image-20240627142134430](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240627142134430.png)

而下面这种情况，是可以把let变量改为const的

```javascript
//let arr=['red','pink']
const arr=['red','pink']
arr.push('blue')
console.log(arr)
```

原因如下图所示，因为arr指向的地址没有变，变得是堆中的内容，只要是栈中的地址不变，就可以将let改变const

![image-20240627143033447](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240627143033447.png)

但是下面这种情况是不行的，因为arr指向的地址发生了变化

```javascript
const arr=['red','pink']
arr.push('blue')
console.log(arr)

arr=[1,2,3] //这样是不行的 会报错的，因为arr指向的地址发生了变化 
```

## 2.2 DOM 介绍

**DOM**（Document Object Model——文档对象模型）是用来呈现及与任意HTML或XML文档交互的API

> **DOM是浏览器提供的一套专门用来操作网页内容的功能**

**DOM作用**：

* 开发网页内容特效
* 实现用户交互



## 2.3 DOM 树

将HTML文档以树状结构直观的表现出来，我们称之为文档树或DOM树

> 其实就是描述网页内容关系的名词

**文档树直观的体现了标签与标签之间的关系。**

* 修改这个对象的属性会自动映射到标签身上

> 比如说修改DOM对象的style属性，那这个DOM对象对应的标签的样式会发生改变

## 2.5 获取DOM元素

我们可以先知道console.dir，后面会用到



**获取DOM元素的方式**

* 根据CSS选择器来获取DOM元素

> 1. querySelector   满足条件的第一个元素
> 2. querySelectorAll  满足条件的元素集合 返回伪数组

* 其他获取DOM元素的方式

> 1. getElementById 根据id获取第一个元素
> 2. getElementsByTagName 根据标签获取一类元素
> 3. getElementsByClassName 根据类名获取一类元素

### 2.5.1 CSS 选择器

我们首先需要选中此标签，和CSS选择器类似，只有选中标签后才能进行操作

查找DOM元素就是利用JS选择页面中的标签元素

**下面会选择匹配第一个元素**

```javascript
 document.querySelector('css选择器')
```

**参数**：包含一个或多个有效的CSS选择器字符串

**返回值**：CSS选择器匹配的第一个元素，一个HTMLElement对象



**下面会选择匹配多个元素**

```javascript
 document.querySelectorAll('css选择器')
```

**参数**：包含一个或多个有效的CSS选择器字符串

**返回值**：CSS选择器匹配的NodeList对象集合

> 这样得到的数组是一个伪数组，有长度有索引号的数组，但是没有pop()、push()等数组方法
>
> 想要得到里面的每一个对象，则需要遍历for的方式获得

****

## 2.6 操作元素内容

其实就是DOM对象的innerText属性和innerHTML属性

* DOM对象都是根据标签生成的，所以操作标签，本质上就是操作DOM对象

**innerText属性使用**

下面说明innerText不解析标签，将内容当做字符串进行展示

```javascript
<body>
<div class="box">文字内容</div>
<script>
  //1.获取元素
  const box = document.querySelector('.box')
  //2.修改文字内容
  console.log(box.innerText)//会在控制台打印 ‘文字内容’
  box.innerText='<strong>我是一个盒子</strong>'
</script>
</body>
```

效果图如下所示

![image-20240628151913953](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240628151913953.png)

**innerHTML属性使用**

会将文本内容添加/更新到任意标签位置

会解析标签，多标签建议使用模版字符串

```javascript
<body>
<div class="box">文字内容</div>
<script>
  //1.获取元素
  const box = document.querySelector('.box')
  //2.修改文字内容
  console.log(box.innerHTML)//会在控制台打印 ‘文字内容’
  box.innerHTML='<strong>我是一个盒子</strong>'
</script>
</body>
```

![image-20240628153035420](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240628153035420.png)

**两者区别**

innerText属性只识别文本，不能解析标签

innerHTML属性能之别文本，能够解析标签



## 2.7 操作元素style属性

### 2.7.1 常用属性修改

常见的属性比如href、title、src等

直接能过属性名修改，最简洁的语法

```javascript
<img src="./images/1.webp" alt="">
<script>
  // 1. 获取 img 对应的 DOM 元素
  const pic = document.querySelector('img')
	// 2. 修改属性
  pic.src = './images/lion.webp'
  pic.width = 400;
  pic.alt = '图片不见了...'
</script>
```

通过这样的方式，修改样式比较少的情况下有优势

这样生成的样式是行内样式，权重比较高，权重高于内部样式表，这种只能通过important将其覆盖掉

### 2.7.2 控制样式属性

**三种方式**：

1. **通过style属性操作CSS**
2. **操作类名（className）操作CSS**
3. **通过classList操作类控制CSS**



* **通过style属性操作CSS**

```javascript
对象.style.样式属性=值
```

通过修改行内样式 `style` 属性，实现对样式的动态修改

通过元素节点获得的 `style` 属性本身的数据类型也是对象

> 如 `box.style.color`、`box.style.width` 分别用来获取元素节点 CSS 样式的 `color` 和 `width` 的值。

任何标签都有 `style` 属性，通过 `style` 属性可以动态更改网页标签的样式，如要遇到 `css` 属性中包含字符 `-` 时，要将 `-` 去掉并将其后面的字母改成大写，如 `background-color` 要写成 `box.style.backgroundColor`

```javascript
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Title</title>
  <style>
      div {
          width: 200px;
          height: 200px;
          background-color: pink;
      }
  </style>
</head>
<body>
<div class="box"></div>
<script>
  //1.获取元素
  const div = document.querySelector('.box')
  //2.修改样式属性
  div.style.width = '300px'
  // css 属性的 - 连接符与 JavaScript 的 减运算符
  // 冲突，所以要改成驼峰法
  div.style.backgroundColor = 'red'
  //添加边框
  div.style.border = '2px solid blue'
</script>
</body>
</html>
```

> 如果选择body的话，可以直接写document.body.style，因为它是唯一的



### 2.7.2 类名操作CSS

如果修改的样式比较多，直接通过style属性修改比较繁琐，我们可以通过借助于css类名的形式

**语法**

```javascript
//active是css类名
元素.className = 'active'
```

```javascript
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Title</title>
  <style>
      div {
          width: 200px;
          height: 200px;
          background-color: pink;
      }

      .box {
          width: 300px;
          height: 300px;
          background-color: rosybrown;
      }
  </style>
</head>

<body>
<div class="nav"></div>

<script>
  //1.获取元素
   const div = document.querySelector('div')
  //2.添加类名
  div.className='box' //box的样式替代了dev的样式
  //div.className='nav box' 既保留了nav的样式，又增加了box样式
</script>
</body>
</html>
```

![image-20240628170824976](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240628170824976.png)

**注意**

1. 由于class是关键字，所以使用className去代替

2. className是使用新值换旧值，如果需要添加一个类，需要保留之前的类名





### 2.7.3 classList操作类控制CSS

我们通过如下的方式修改时，一定要去原标签查看一下有没有原始的类名，以防后来的类的样式覆盖之前的

```javascript
div.className='nav box'
```

这样每次去找之前样式的类其实挺麻烦的，

为了解决className容易覆盖以前的类名问题，我们可以通过classList方式追加和删除类名，也是我们的**终极解决方案**

**语法**

```javascript
//追加一个类  这里如果是类名的话，不用加“.”
元素.classList.add('类名')

//删除一个类
元素.classList.remove('类名')

//切换一个类
元素.classList.toggle('类名')
```

**案例**

```javascript
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        div {
            width: 200px;
            height: 200px;
            background-color: pink;
        }

        .active {
            width: 300px;
            height: 300px;
            background-color: hotpink;
            margin-left: 100px;
        }
    </style>
</head>

<body>
    <div class="one"></div>
    <script>
        // 1.获取元素
        // let box = document.querySelector('css选择器')
        let box = document.querySelector('div')
        // add是个方法 添加  追加
        // box.classList.add('active')
        // remove() 移除 类
        // box.classList.remove('one')
        // 切换类
        box.classList.toggle('one')
    </script>
</body>

</html>
```

**className和classList有什么区别**？

* classList修改大量样式更方便

* className是追加和删除，不影响以前的类名

* className修改不多的样式的时候更方便

  



## 2.8 操作表单元素属性

表单很多情况也需要修改属性，比如点击眼镜可以看到密码，本质就是把表单类型转换为文本框

> password的时候看不到，text的时候可以看到

![image-20240701141742414](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240701141742414.png)

正常的有属性有取值的，跟其他的标签属性没有任何区别

**获取**：DOM对象.属性名

> 注意，表单不通过innerHTML获取的
>
> uname.innerHTML是获取不到的

```javascript
<body>
<label>
  <input value="电脑" type="text" placeholder="请输入信息">
</label>
<script>
  //1.获取元素
  const uname = document.querySelector('input')
  //2.获取用户输入的值
  console.log(uname.value)
</script>
</body>
```

**设置**：DOM对象.属性名=新值

```javascript
uname.value='你长得好帅'
```



* 表单属性中添加就有效果，移除就没有效果，一律使用布尔值表示，如果为true则代表添加了该属性，如果为false则代表移除了该属性

> 比如disabled、checked、selected，就可以实现下图中的复选效果

![image-20240701143129312](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240701143129312.png)

```javascript
<body>
<label>
  <input type="checkbox" id="" name="">
</label>
<script>
  //1.获取
  const ipt = document.querySelector('input')
  console.log(ipt.checked) //false
  ipt.checked=true //ipt.checked为true
</script>
</body>
```



## 2.9 自定义属性

**标准属性**：标签天生自带的属性，比如class id title等

**自定义属性**：

* 在html5中推出来的专门的"data-"自定义属性
* 在标签上一律以"data-"开头
* 在DOM对象上一律以dataset对象方式获取

```javascript
<body>
<div data-id="1">1</div>
<div data-id="2">2</div>
<div data-id="3">3</div>
<div data-id="4">4</div>
<div data-id="5">5</div>
<div data-id="6">6</div>
<script>
  const one = document.querySelector('div')
  console.log(one.dataset.id)
</script>
</body>
```
