# 一、函数

函数可以把具有相同或相似逻辑的代码“包裹”起来，通过函数调用执行这些被“包裹”的代码逻辑，这么做的优势是有利于精简代码方便复用。

> 主要是为了实现代码的复用
>
> 之前见过的alert()、prompt()、console.log()都是一些封装好的js函数

## 1.1 函数使用

**声明函数**

```javascript
function 函数名(){
    函数体
}
```

![img](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/function.jpg)

> 函数名的命名规则与变量是一致的，尽量使用小驼峰式命名法
>
> 并且尽量保证函数名的语义



**调用函数**

声明的函数必须调用才会真正被执行

```javascript
//后面的小括号是在调用
函数名()
```



```javascript
  <script>
    // 声明（定义）了最简单的函数，既没有形式参数，也没有返回值
    function sayHi() {
      console.log('嗨~')
    }
    // 函数调用，这些函数体内的代码逻辑会被执行
    // 函数名()
        
    sayHi()
    // 可以重复被调用，多少次都可以
    sayHi()
  </script>
```



## 1.2 函数传参

**通过向函数传递参数，可以让函数更加灵活多变，参数可以理解成是一个变量**

```javascript
function 函数名(参数列表){
    函数体
}
```



**声明（定义）一个功能为打招呼的函数**

- 传入数据列表
- 声明这个函数需要传入几个数据
- 多个数据用逗号隔开

```javascript
    function sayHi(name) {
      // 参数 name 可以被理解成是一个变量
      console.log(name)
      console.log('嗨~' + name)
    }

    // 调用 sayHi 函数，括号中多了 '小明'
    // 这时相当于为参数 name 赋值了
    sayHi('小明')// 结果为 小明

    // 再次调用 sayHi 函数，括号中多了 '小红'
    // 这时相当于为参数 name 赋值了
    sayHi('小红') // 结果为 小红
```

**总结**：

1. 声明（定义）函数时的形参没有数量限制，当有多个形参时使用 `,` 分隔
2. 调用函数传递的实参要与形参的顺序一致



**形参与实参**：

* **形参**：声明函数时写在函数名右边小括号里的叫形参（形式上的参数）

* **实参**：调用函数时写在函数名右边小括号里的叫实参（实际上的参数）

形参可以理解为是在这个函数内声明的变量（比如 num1 = 10）实参可以理解为是给这个变量赋值

> 开发中尽量保持形参和实参个数一致，否则可能影响正常业务的执行

```javascript
  <script>
    // 声明（定义）一个计算任意两数字和的函数
    // 形参 x 和 y 分别表示任意两个数字，它们是两个变量
    function count(x, y) {
      console.log(x + y);
    }
    // 调用函数，传入两个具体的数字做为实参
    // 此时 10 赋值给了形参 x
    // 此时 5  赋值给了形参 y
    count(10, 5); // 结果为 15
  </script>
```

还可以传入默认的参数

```javascript
  //避免NaN的情况
  function count(x=0, y=0) {
      console.log(x + y);
  }
```





## 1.3 函数返回值

函数的本质是封装（包裹）

函数体内的逻辑执行完毕后，函数外部如何获得函数内部的执行结果呢？

要想获得函数内部逻辑的执行结果，需要通过**retur关键字**，将内部执行结果传递到函数外部，这个被传递到外部的结果就是返回值

```javascript
  <script>
    // 定义求和函数
    function count(a, b) {
      let s = a + b
      // s 即为 a + b 的结果
      // 通过 return 将 s 传递到外部
      return s
    }

    // 调用函数，如果一个函数有返回值
    // 那么可将这个返回值赋值给外部的任意变量
    let total = count(5, 12)
  </script>
```

**总结**：

1. 在函数体中使用return 关键字能将内部的执行结果交给函数外部使用
2. 函数内部只能出现1 次 return，并且 return 下一行代码不会再被执行，所以return 后面的数据不要换行写
3. return会立即结束当前函数
4. 函数可以没有return，这种情况默认返回值为 undefined



## 1.4 作用域

**一段程序代码中所用到的名字并不总是有效和可用的，而限定这个名字的可用性的代码范围就是作用域**

下面的情况使用时会报错，报错的原因和作用域相关

![image-20240626152651664](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240626152651664.png)

**在变量处有坑**

* 如果函数内部，变量没有声明，直接赋值，也当全局变量看，但是强烈不推荐这么使用

* 函数内部的形参可以看做是局部变量
* 变量的访问规则是，在能够访问到的情况下，先局部，局部没有再找全局



### 1.4.1 全局作用域

作用于所有代码执行的环境(整个 script 标签内部)或者一个独立的 js 文件

处于全局作用域内的变量，称为全局变量

```javascript
<script>
    let num=10 //在此文件中是全局变量
</script>
```



### 1.4.2 局部作用域

作用于函数内的代码环境，就是局部作用域。 因为跟函数有关系，所以也称为函数作用域。

处于局部作用域内的变量称为局部变量

```javascript
<script>
   function fun(){
    let str = 'zhangsan' //局部变量
  }
</script>
```



## 1.5 匿名函数

函数可以分为具名函数和匿名函数

匿名函数：没有名字的函数,无法直接使用

![image-20240626154458935](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240626154458935.png)



**使用方式**：

* 函数表达式
* 立即执行函数

### 1.5.1 函数表达式

将匿名函数赋值给一个变量，并且通过变量名称进行调用，我们称这个位**函数表达式**

```javascript
// 声明
let fn = function() { 
   console.log('函数表达式')
}
// 调用 调用的时候一定要在let fn之后
fn()
```



```javascript
// 声明
let fn = function(x,y) { 
   console.log('函数表达式')
}
// 调用 调用的时候一定要在let fn之后
fn(1,2)
```



> 具名函数和函数表达式的区别：
>
> 具名函数的调用可以写到任何位置
>
> 函数表达式的时候必须先声明函数表达式，后调用



### 1.5.2 立即执行函数

避免全局变量之间的污染

**语法**

```javascript
(function()
 {
    xxx  
 }) ();
  

(function()
 {
    xxxx
  }()
);
```



>其实可以这么看： (函数)(); 第一个括号把函数包裹起来了，第二个小括号是调用函数



>无需调用，立即执行，其实本质已经调用了
>
>多个立即执行函数之间用分号隔开



比如正常使用的话

```javascript
(function(x,y) //形参
 {
    xxx  
 }) (1,2);//实参
```



# 二、逻辑中断

之前我们为了避免计算时出现NaN的情况，使用下面的这种方式

```javascript
  //避免NaN的情况
  function count(x=0, y=0) {
      console.log(x + y);
  }
```

如今我们可以换个方式，这种方式其实就叫逻辑中断

```javascript
  //避免NaN的情况
  function count(x, y) {
      x = x || 0 //若x是假的话，我们就拿到后面的0
      y = y || 0 //同理
      console.log(x + y);
  }
```

* **短路**

只存在于&&和||中，当满足一定条件的时候不让右边的代码执行

因为左边的表达式已经能获取到最终结果了，没必要再执行右边的代码

![image-20240626163255338](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240626163255338.png)

```javascript
console.log(10 && 20) //20

console.log(0 && 20) //0

console.log(undefined && 20) //undefined

console.log(null && 20)// null

console.log(10 || 20) //10
```





# 三、转换为boolean

* **显示转换**

''空串、0、undefined、null、false、NaN转换为布尔值后都是false，其余则为true

> 假如说将undefined转换成数字，会变成NaN
>
> ![image-20240626165534918](https://picture-typora-zhangjingqi.oss-cn-beijing.aliyuncs.com/image-20240626165534918.png)

* **强制转换成boolean值**

```javascript
console.log(Boolean('zhangsan')) //true
```
